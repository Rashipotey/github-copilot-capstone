No branch/range or interactive selection; no deleted content is analyzed. | R-01, R-07; AC-01, AC-06; architecture: changed inputs/data flow; revision 4 review. |
| **G-04 — Candidate evidence semantics** | Use repo-relative POSIX paths. Path-reference matching is exact and case-sensitive. Source stems, symbols, and configuration keys match as exact case-sensitive tokens; ASCII letters, digits, and underscore are token characters. Source stem is the filename-similarity signal. Shared directory means exact equality of immediate parent paths. Candidate set is the union of signals; record every reason, with no score or precedence. Multiple distinct candidate paths are conflict/ambiguity and follow G-02; zero matching signals are insufficient evidence and mean “no relationship established.” No candidate is confirmed or verified. | R-01–R-03, R-05, R-06; AC-01, AC-02, AC-04, AC-05; architecture: G-04/matching rules; DR3-01 resolved. |
| **G-05 — Complete, partial, and fatal outcomes** | Fatal: Git/change-set acquisition failure, unsafe configuration/output path, or required decoding/screening safety failure; return sanitized error and write no report. Deleted, unsupported, out-of-scope, size-limited, unreadable, or parse-failed items are unanalyzed and contribute no content. Complete: all required eligible evidence analyzed and no unanalyzed inputs; write report and return success, including empty findings. Partial: if any inputs are unanalyzed, write a clearly labeled report and return nonzero only when at least one eligible source was successfully decoded, screened, and analyzed—including a no-relationship result; otherwise write no report. Skipped items never count as analyzed. | R-07, R-09; AC-06, AC-08; architecture: G-05/data flow; DR3-02 resolved. |
| **G-06 — Output-path and publication safety** | Require an existing configured output directory; validate resolved paths and reject symlink/junction traversal; ensure the report remains within that directory; refuse collisions and publish exclusively without replacement; clean temporary files on failure. Write only the fixed report, never a patch. | R-04, R-08; AC-03, AC-07; architecture: path boundary/publisher. |
